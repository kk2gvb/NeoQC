# Варианты строки символики

`index.html` содержит пять отдельных современных композиций строки с символикой БГМУ
и программы «Приоритет 2030».

Варианты намеренно не подключены к полному макету. После выбора одна композиция заменит
текущую строку одновременно в шапке и на закрывающей странице отчёта.

Во всех вариантах используются только официальные ресурсы из `assets/report/branding`,
фирменная палитра и одинаковый текст. Это позволяет сравнивать именно композицию, а не
разное содержание.
