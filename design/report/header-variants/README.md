# Варианты шапки

Откройте `index.html` в браузере: на одной странице представлены три независимых
направления оформления.

1. **Институциональный** — тёмно-синий блок в стилистике официального сайта БГМУ.
2. **Клинический** — светлый документ с минимальным расходом краски и спокойной иерархией.
3. **Партнёрский** — отдельная верхняя полоса подчёркивает поддержку программы
   «Приоритет 2030».

Это только макеты для выбора. Они ещё не подключены к Python-генератору. После выбора
одного направления его разметка будет перенесена в модуль отчёта, покрыта тестами и
зафиксирована отдельным коммитом.

Выбран вариант 1 — **институциональный**. Его развитие в полный схематичный отчёт
находится в `../full-report/index.html`.
