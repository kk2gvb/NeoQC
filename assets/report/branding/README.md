# Ресурсы фирменного оформления отчёта

- `bgmu-emblem.svg` — основной векторный герб Башкирского государственного медицинского
  университета. Получен из PDF-совместимого AI-файла в предоставленном архиве
  `Логотип (вектор).rar` без растеризации.
- `bgmu-emblem.png` — резервная растровая версия герба (исходный файл `logo (3).png`).
- `priority-2030-color.svg` — основная цветная кириллическая версия логотипа программы
  «Приоритет 2030» из архива `01. Логотип.zip`.
- `priority-2030-white.svg` — официальная версия для тёмного фона из того же архива.
- `priority-2030-mark.svg` — официальная сокращённая цветная версия из архива
  `01.2 Сокращенная версия логотипа.zip`.
- `priority-pattern.svg` — декоративная композиция из квадратных модулей для шапки и
  закрывающей страницы. Построена по принципу паттерна из предоставленного брендбука и
  использует его фирменную палитру.
- `palette.css` — единый справочник HEX-значений фирменной палитры для HTML-макетов и
  будущей интеграции с генератором.

## Палитра

| Назначение | HEX |
|---|---|
| Текст на светлом фоне | `#0A132D` |
| Основной синий | `#2947A0` |
| Дополнительный синий | `#192F70` |
| Тёмный синий фон | `#031E4F` |
| Акцентный зелёный | `#539D96` |
| Текст на тёмном фоне | `#FFFFFF` |

Цвет `#104A76`, ранее взятый из визуального оформления сайта БГМУ, исключён из макета:
он отсутствует в предоставленной фирменной палитре.

Логотипы «Приоритет 2030» используются без изменения цветов, компоновки и пропорций.
В соответствии с предоставленным брендбуком основной является полная версия логотипа;
сокращённая применяется только там, где полная версия становится нечитаемой.

Исходные ZIP-архивы и PDF-брендбук служат справочными материалами и не требуются для
генерации HTML-отчёта.
