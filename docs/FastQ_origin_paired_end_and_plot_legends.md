## Откуда берутся FastQ-файлы

**FastQ** — это стандартный текстовый формат хранения данных секвенирования нового поколения (NGS).  
Каждый FastQ-файл содержит:
- последовательность нуклеотидов (reads);
- качество каждого основания (Phred quality scores);
- идентификатор рида.

Пример:

```fastq
@SEQ_ID:1:POOL:123:456:789
GATCGATCGATCGATCGATCGATCGATC
+
FFHHHHJJJJJJJJJJJJJJJJJJJJJJ
```

## Как появляются R1 и R2

Для single-end sequencing одно исходное прочтение секвенируется с одного направления:

```
Library
|-----------------------------|

──────────────────────────────►
             R1
```

В результате для образца получается один основной FASTQ-файл:

```
sample_R1.fastq.gz
```

Для paired-end sequencing тот же фрагмент читается с двух сторон(это используется для того чтобы минимизировать количество неправильных чтений, так как к концу прочтения качество ухудшается):

```
Library
|-----------------------------------------------------|

──────────────────────────────►
             R1
						◄──────────────────────────────
										R2
	             
```

Поэтому создаются два файла:
```
sample_R1.fastq.gz
sample_R2.fastq.gz
```

`R1` и `R2` являются двумя сторонами одного paired-end прочтения. Их записи должны оставаться согласованными по идентификаторам.

## Графики и пояснение к ним

### Глосарий:

- **position** — позиция основания внутри прочтения;
- **read** — отдельное прочтение;
- **R1 / R2** — первое и второе прочтение пары при paired-end секвенировании;
- **quality** — значение качества основания по шкале Phred.
### 1. Per-base sequence quality

**Назначение:** оценка качества секвенирования в зависимости от позиции основания в прочтении.

- **Ось X** — позиция основания в прочтении.
- **Ось Y** — значение качества Phred.
- Каждая точка соответствует определённой позиции в прочтении.

### Кривые

| Кривая                  | Что показывает                                                                    |
| ----------------------- | --------------------------------------------------------------------------------- |
| **Mean quality**        | Среднее качество оснований на данной позиции                                      |
| **Lower quartile (Q1)** | Нижняя граница, ниже которой находится примерно 25% наблюдений                    |
| **Median (Q2)**         | Медианное качество: половина наблюдений имеет значение ниже него, половина — выше |
| **Upper quartile (Q3)** | Верхняя граница, ниже которой находится примерно 75% наблюдений                   |

Если на графике используется только **Mean quality**, то именно эта линия является основной характеристикой качества по позициям.

### Что позволяет увидеть

График позволяет определить:

- снижение качества к концу прочтения;
- резкие провалы качества на отдельных позициях;
- различие качества между началом и концом прочтения;
- различия между **R1 и R2**.

Для качественных данных обычно ожидается относительно стабильное качество с возможным постепенным снижением к концу прочтения.

---

### 2. Per sequence quality scores

**Назначение:** оценка распределения качества по всему набору секвенированных данных.

Здесь важно отличать этот график от Per-base sequence quality.

**Per-base sequence quality** отвечает на вопрос:

> «Как меняется качество в зависимости от позиции внутри прочтения?»

А **Quality distribution**:

> «Как распределено качество среди всех оснований/наблюдений в наборе данных?»

### Кривые / элементы графика

В текущей реализации NeoQC это **распределение количества наблюдений для каждого значения качества**.

- **Ось X** — значение качества.
- **Ось Y** — количество наблюдений.

Каждый столбец показывает, сколько оснований имеет соответствующее значение качества.

### Что позволяет увидеть

График позволяет быстро определить:

- преобладающий диапазон значений качества;
- наличие большого количества низкокачественных оснований;
- смещение распределения в сторону высоких или низких значений;
- общую картину качества данных.

---

### 3. Adapter content

**Назначение:** определение наличия последовательностей адаптеров в прочтениях и их доли по мере продвижения вдоль прочтения.

Адаптеры — технические последовательности, добавляемые при подготовке библиотеки и не являющиеся частью исходной биологической последовательности.

- **Ось X** — позиция в прочтении.
- **Ось Y** — доля прочтений, содержащих соответствующую адаптерную последовательность.

### Кривые

Каждая линия соответствует **отдельному адаптеру** или адаптерной последовательности.

Например:

| Кривая    | Значение                                |
| --------- | --------------------------------------- |
| Adapter 1 | Доля прочтений с обнаруженным Adapter 1 |
| Adapter 2 | Доля прочтений с обнаруженным Adapter 2 |
| ...       | Аналогично для остальных адаптеров      |

В данной реализации используются следующие адаптеры: TruSeq(illuminia), SmallRNA3', SmallRNA5', Nextera
### Что позволяет увидеть

Рост содержания адаптера к концу прочтений может указывать на то, что:

- длина вставки меньше длины прочтения
- секвенирование «зашло» в адаптерную последовательность;
- перед последующим анализом может потребоваться adapter trimming.

Таким образом, график используется для контроля необходимости удаления адаптеров.

---

### 4. Per-base sequence content

**Назначение:** оценка состава нуклеотидов в каждой позиции прочтения.

- **Ось X** — позиция основания.
- **Ось Y** — процентное содержание нуклеотида.

### Кривые

На графике отображаются пять основных линий:

| Кривая | Что показывает                |
| ------ | ----------------------------- |
| **A**  | Доля аденина в данной позиции |
| **C**  | Доля цитозина                 |
| **G**  | Доля гуанина                  |
| **T**  | Доля тимина                   |
| **N**  | Доля неопределённых оснований |

Для каждой позиции сумма долей A, C, G, T и N должна быть близка к 100%.

### Что позволяет увидеть

График используется для обнаружения:

- выраженного дисбаланса нуклеотидов;
- систематических смещений в начале прочтений;
- аномального состава библиотеки;
- наличия большого количества неопределённых оснований.

При этом сам по себе неравномерный состав не обязательно означает ошибку: он может быть обусловлен особенностями биологического материала, типа библиотеки или протокола секвенирования.

---

### 5. Per-sequence GC content

**Назначение:** анализ распределения GC-состава между прочтениями.

В отличие от Per-base sequence content, здесь рассматривается **GC-содержание целого прочтения**, а не отдельной позиции.

- **Ось X** — процент GC в прочтении.
- **Ось Y** — количество прочтений.

### Элементы графика

Каждый столбец соответствует определённому диапазону GC-содержания и показывает, сколько прочтений попало в этот диапазон.

Например:

> 40% GC → количество прочтений с GC-содержанием около 40%.

### Что позволяет увидеть

График позволяет определить:

- типичный GC-состав образца;
- ширину распределения;
- наличие нескольких выраженных пиков;
- необычное смещение GC-состава;
- возможную неоднородность состава библиотеки.

---

### 6. Per-base N content

**Назначение:** оценка количества неопределённых оснований `N` в каждой позиции прочтения.

- **Ось X** — позиция основания.
- **Ось Y** — процент оснований `N`.

### Кривая

Здесь используется одна основная кривая:

**N content** — процент прочтений, в которых в соответствующей позиции находится неопределённое основание `N`.

### Что позволяет увидеть

Рост N-content может указывать на проблемы с определением основания при секвенировании или снижение качества сигнала.

Особенно информативно наличие:

- резких пиков;
- устойчивого роста N к концу прочтения;
- аномально высокого N-content на отдельных позициях.

---

### 7. Sequence length distribution

**Назначение:** оценка распределения длин прочтений в FASTQ-файле.

- **Ось X** — длина прочтения в нуклеотидах.
- **Ось Y** — количество прочтений.

### Элементы графика

Каждый столбец показывает количество прочтений определённой длины.

Например:

> 150 nt → количество прочтений длиной 150 нуклеотидов.

### Что позволяет увидеть

График позволяет определить:

- является ли длина прочтений однородной;
- соответствует ли она ожидаемой длине секвенирования;
- присутствуют ли укороченные прочтения;
- имеется ли несколько групп прочтений разной длины.

Для парных данных распределения **R1 и R2** могут анализироваться отдельно.

---
### 8. Sequence Duplication Levels

**Назначение:** оценка степени дублирования прочтений в исследуемом наборе данных.

График показывает, какая доля прочтений встречается в данных один раз, два раза, три раза и более.

- **Ось X** — уровень дублирования последовательности, то есть сколько раз одна и та же последовательность встречается в FASTQ.
- **Ось Y** — доля прочтений или последовательностей, относящихся к соответствующему уровню дублирования.

### Кривые / элементы графика

Каждый элемент графика соответствует определённому **уровню дублирования**:

| Уровень | Значение                                                        |
| ------- | --------------------------------------------------------------- |
| **1**   | Последовательность встречается один раз                         |
| **2**   | Одна и та же последовательность встречается два раза            |
| **3**   | Последовательность встречается три раза                         |
| **4**   | Четыре раза                                                     |
| **…**   | И так далее                                                     |
| **10+** | Высокие уровни повторения, если они объединены в одну категорию |

### Что означает высокий уровень дублирования

Большое количество одинаковых прочтений может быть связано с разными причинами:

- PCR-амплификацией библиотеки;
- высокой представленностью отдельных молекул;
- особенностями самого биологического материала;
- низкой сложностью библиотеки;
- техническими особенностями подготовки библиотеки.

Поэтому высокий уровень дублирования **не следует автоматически считать ошибкой**. Его необходимо интерпретировать с учётом типа эксперимента и библиотеки.

### Что позволяет увидеть

График позволяет ответить на вопрос:

> **«Насколько значительная часть данных состоит из повторяющихся последовательностей?»**

Это важно при оценке эффективной сложности библиотеки и потенциального количества независимых молекулярных наблюдений.

---

### 9. Overrepresented sequences

**Назначение:** выявление конкретных последовательностей, которые встречаются в данных значительно чаще остальных.

В отличие от **Sequence Duplication Levels**, который показывает **общую степень дублирования**, этот график/отчёт позволяет определить **конкретные последовательности**, являющиеся наиболее частыми.

### Оси

Если график представлен в виде распределения:

- **Ось X** — последовательность или категория последовательности;
- **Ось Y** — количество или доля её встречаемости.

Если в отчёте используется список, каждая строка соответствует отдельной наиболее часто встречающейся последовательности.

### Элементы

Каждый элемент соответствует **конкретной последовательности**, обнаруженной среди наиболее часто встречающихся.

Например:

| Последовательность | Что показывает                                       |
| ------------------ | ---------------------------------------------------- |
| Sequence 1         | Конкретная последовательность и её частота           |
| Sequence 2         | Следующая наиболее представленная последовательность |
| Sequence 3         | Ещё одна часто встречающаяся последовательность      |

### Почему это важно

Чрезмерно представленная последовательность может быть:

- частью адаптера;
- праймером;
- техническим артефактом;
- рРНК или другим высоко представленным транскриптом;
- последовательностью, действительно характерной для исследуемого материала.

Поэтому обнаружение overrepresented sequence само по себе **не означает плохое качество данных**. Необходимо определить происхождение последовательности.

### Что позволяет увидеть

График отвечает на вопрос:

> **«Есть ли в библиотеке конкретные последовательности, которые встречаются подозрительно часто?»**

Это особенно полезно для обнаружения технических последовательностей, которые могут требовать дополнительной фильтрации или trimming.
