# Аудит HTML-отчёта NeoQC (дизайн «Геномный браузер»)

Дата: 26.09.2026. Объём: новый HTML-отчёт (`scripts/qc_report.py`), стиль и
локализация графиков (`scripts/plot_style.py`, `scripts/plot_metrics.py`,
`scripts/neoqc_theme.py`, `scripts/neoqc_i18n.py`), шрифты
(`assets/fonts/ibm-plex/`), тесты и документация по отчёту.

Описание отчёта — [`../html-report.md`](../html-report.md).

## 1. Что изменено

- Новый интерфейс отчёта: верхняя панель, левая панель с навигацией и
  ячейками статусов R1/R2, панели модулей с дорожками R1/R2.
- Режимы порядка «Приоритет» / «По порядку», сворачивание панелей.
- Светлая и тёмная тема, в том числе для графиков.
- Английский и русский язык интерфейса и графиков (`*.ru.svg`).
- Графики встраиваются как очищенный SVG вместо `data:`-картинок; шрифты IBM
  Plex (латиница + кириллица) встроены в отчёт и используются Matplotlib.
- Из отчёта убраны внутренние подписи разработчика (подзаголовок о
  «self-contained report», имена файлов и идентификаторы модулей).

## 3. Найденные и исправленные дефекты

### Технические

| № | Дефект | Исправление |
|---|---|---|
| T1 | Встраивание SVG в HTML открывает путь для внедрения скриптов, если файлы в `plots/` подменены (в `<img>` скрипты не исполнялись) | SVG разбирается как XML и очищается по списку разрешённых элементов; удаляются `script`, `foreignObject`, `image`, `style`, `on*`, внешние ссылки; `<!ENTITY>` отклоняется |
| T2 | Matplotlib пишет в SVG глобальное правило `<style>*{stroke-linecap: butt}</style>`; во встроенном виде оно действует на всю страницу и меняет иконки интерфейса | `<style>` удаляется, правило задано в CSS отчёта только для `.chart-svg` |
| T3 | Одинаковые `id` (`clipPath`, маркеры) в разных графиках конфликтуют на одной странице | префикс `<модуль>-<рид>-<язык>-` для всех `id`, `href` и `url(#…)` |
| T4 | Первая версия санитайзера отклоняла стандартный `<!DOCTYPE svg …>` от Matplotlib — все графики пропадали | разрешён DOCTYPE без внутреннего подмножества; `<!ENTITY>` и `[…]` по-прежнему отклоняются |
| T5 | Отсутствие русского SVG одного графика скрывало и английский | при ошибке перевода показывается английский график в обоих языках |
| T6 | График GC использовал цвета `'red'`, `'green'`, `'dodgerblue'` вне палитры: не перекрашивались бы в тёмной теме | цвета палитры; тест запрещает любой цвет SVG вне палитры |
| T7 | График GC сдвигал `ax.texts[0]` под свой заголовок — хрупкая зависимость от порядка текстов | заголовки внутри фигур убраны (их показывает панель), обходной код удалён |
| T8 | Подсветка навигации указывала на соседний раздел, если выбранный раздел находится у конца страницы | выбранный пользователем раздел имеет приоритет, пока он виден |
| T9 | В режиме «Приоритет» модули `NOT EVALUATED` сворачивались вместе с прошедшими | `NOT EVALUATED` входит в «Требует внимания» и не сворачивается |
| T10 | Печать из тёмной темы давала тёмный PDF | `@media print` задаёт светлые переменные; `beforeprint` временно включает светлую тему |
| T11 | В печатной версии пропадали дата создания и сведения верхней панели | дата печатается в блоке обзора (`print-meta`) |
| T12 | SVG ссылались на шрифт DejaVu Sans; на Windows его нет, и браузер подставлял Times (подписи с засечками) | шрифты IBM Plex встроены в отчёт; у текста в SVG есть запасные семейства |
| T13 | Встроенный шрифт содержал только латиницу — русские подписи на графиках рисовались системным шрифтом с засечками | добавлены кириллические подмножества с `unicode-range` |
| T14 | `tick_params(labelfontfamily=…)` появился в Matplotlib 3.8, а `requirements.txt` допускает 3.7 | запасной путь для 3.7 в `finish_figure()` |
| T15 | `neoqc` падал с «Cannot open adapter config» при запуске не из корня репозитория (относительный путь `config/adapters/…`) | CMake передаёт абсолютный путь `NEOQC_ADAPTER_CONFIG`, как уже сделано для `NEOQC_PLOT_SCRIPT` |
| T16 | При `--formats png` отчёт не показывал бы графики (ожидался SVG) | PNG встраивается как изображение; тест `test_png_only_run_has_no_localized_svg` |

## 4. Осталось (осознанные ограничения)

- Статусы (`PASS`, `WARNING`, `FAIL`, `NOT EVALUATED`, `INFO`) и названия
  адаптеров не переводятся — принятые обозначения.
- Сообщения пользовательских наборов правил переводятся, только если их
  название есть в словаре `UI`.
- Разделители разрядов — запятые (`19,564`) и в русском режиме.
- Нет автоматической браузерной проверки (скриншоты, печать) в `ctest`: для
  этого нужен Playwright/Chromium в окружении сборки. Действует ручной
  чек-лист из `html-report.md`, раздел 16; синтаксис JavaScript проверяется
  тестом через `node --check`.
- Шрифты добавляют в репозиторий ≈ 0,8 МБ, в каждый отчёт — ≈ 0,3 МБ.
- При узком окне (< 1000 px) без JavaScript список разделов остаётся свёрнутым.
