# Модуль HTML-отчёта

Модуль отделяет расчёты пайплайна от представления клинического документа. Аналитический
код заполняет только структуры из `include/html_report.h`; HTML, CSS и экранирование
полностью остаются внутри рендерера.

## Публичный контракт

- `ReportData` — шапка документа, метаданные, разделы и итоговые выводы.
- `Section` — самостоятельный смысловой раздел с кратким текстом, метриками и таблицами.
- `Metric` — подпись, строковое значение, единица измерения, референс и статус.
- `Status` — `notEvaluated`, `passed`, `warning` или `failed`.
- `renderHtmlReport(...)` — возвращает готовый HTML строкой.
- `writeHtmlReport(...)` — атомарно сохраняет автономный HTML-файл.

Значения метрик намеренно являются строками. Форматирование чисел, округление и обозначение
отсутствующих данных контролирует аналитический код, а рендерер не меняет научный смысл.
Все переданные значения трактуются как обычный текст и безопасно экранируются. Передавать
HTML-теги в поля структур не следует.

Минимальный рабочий пример находится в `examples/html_report_example.cpp`. Он собирается
как `html_report_example` и создаёт `mrna_report_example.html` в текущем каталоге.

## Граница интеграции

Текущий `main.cpp` не изменён и автоматически отчёт не создаёт. После согласования состава
клинического документа интеграционный код должен преобразовать результаты анализа в один
`ReportData` и вызвать:

```cpp
neoqc::report::writeHtmlReport(report, outputDirectory / "report.html");
```

Так расчётный код не зависит от разметки отчёта, а дизайн отчёта не затрагивает обработку
FASTQ и существующие текстовые/TSV-результаты.
